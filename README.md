## Nama Project
C++ Sorting Project

## Deskripsi Project
Program ini menerima input sejumlah bilangan bulat, mengurutkannya, dan mencetak nilai median dari sekelompok bilangan.

## Cara Menjalankan
1. Compile file:
   ```bash
   g++ M.cpp -o sort

2. Jalankan program:
   ```bash
   ./sort
   
4. Masukkan jumlah kelompok a lalu 3*a angka.
5. Contoh input:
   ```bash
   2
   9 5 1 4 7 6
6. Output:
   ```bash
   5
